# 04 · 页面结构与样式体系

## 1. 视觉方向

`style.css` 开头定义了整站的视觉基调：

> 方格纸学习手账 —— 暖米色纸底 / 墨蓝字迹 / 朱红批注

对应到实现：

- 纸底：`--paper` + 26px × 26px 的双向网格渐变（`--grid`）；
- 装订线：固定定位的 `.margin-line`（视口中线再左移 46px；1px 朱红渐变线 + 4px 阴影），`<= 880px` 隐藏；
- 暗角：`body::before` 两层径向渐变，避免纯平底色；
- 字体：标题用衬线（宋体栈），正文用无衬线（苹方 / 雅黑栈），数字用等宽（JetBrains Mono / Consolas 栈）并开启 `tabular-nums`。

`DESIGN.md` 是设计决策的事实文档，代码只是它的实现。改界面前先读它，尤其是「信息归属」与「颜色语义」两节。

要点：

- **页面骨架是静态的**，`app.js` 只填充内容区（`#todayList`、`#courseList`、`#todoList`、`#calGrid`、`#heatmap`、预览表等），不动态创建整块视图。
- 三个视图用 `hidden` 切换，而非 `display:none` 内联；页签与面板的 `aria-*` 由 `setView` 同步维护。
- 弹层都带 `.modal-backdrop` + `role="dialog"` + `aria-modal="true"`，焦点进入关闭按钮，关闭后回到触发元素。
- `?v=20261108-15` 是 CSS / JS 的缓存版本号，发版时两个文件要同步改（否则用户可能拿到旧脚本配新样式）。

## 3. 三视图的信息归属

| 信息 | 只出现在 | 说明 |
| --- | --- | --- |
| 视频时长 | 学习视图（今日卡 / 统计卡 / 热力图）+ 日历日期格、当日明细 | 待办视图不显示时长 |
| 逾期 / 今日 / 本周计数 | 待办视图（全局口径） | 日历只显示「本月逾期 / 本周截止」 |
| 课程与课时编辑 | 学习视图 | 日历明细只引用课程名，不提供编辑 |
| 待办增删改 | 待办视图 + 待办弹层 | 学习 / 日历只读展示 |
| 循环打卡 | 学习视图（今日卡之后） | 视频打卡的分钟直接进课时进度与热力图，自定义打卡不计分钟 |
| 完成待办 / 打卡次数 | 今日卡指标 + 当日详情 + 日历格子 | 与视频时长并列呈现，构成「学习量」的三个口径 |
| 热力图 | 学习视图 | 日历用色点表达截止，不画第二套热力图 |
| B 站导入 | 学习视图（页面底部折叠面板） | 切到待办 / 日历即隐藏，输入与预览状态保留 |

首屏顺序固定为：品牌头 → 三视图页签 → 今日摘要 → 循环打卡 → 统计卡 → 热力图 → 课程区。

| --- | --- | --- |

| `--red` | `#c0453a` | 朱红：进度环、页签选中下划线、焦点环、危险操作文字、品牌强调 |
| `--red-deep` | `#9e3128` | 红色悬停 / 深色批注 |
| `--rule` | `#d9d1be` | 面板描边 |

**颜色纪律**：红 / 橙 / 黄 / 灰蓝这四色只用于「紧急度」。类别只用中性文字标签，完成状态只用 `✓ / ○` + 删除线 + 降低透明度，不再另起色板。

### 4.2 字体与尺寸

| Token | 值 |
| --- | --- |
| `--font-serif` | Songti SC / STSong / Source Han Serif SC / Noto Serif SC / SimSun |
| `--font-sans` | PingFang SC / Hiragino Sans GB / Microsoft YaHei / Source Han Sans SC |
| `--font-mono` | JetBrains Mono / SFMono-Regular / Consolas / Courier New |
| `--radius` | `4px`（面板、卡片、按钮、输入统一使用它） |
| `--shadow` | `0 1px 2px` 贴地阴影 + `0 8px 24px -12px` 柔和扩散 |

字号实测：`body` 15px；`h1` `clamp(30px, 4.4vw, 46px)`；视图页签 15px；面板标题 19px；按钮 13.5px；辅助说明 11–12.5px。

`DESIGN.md` 是设计意图，当前 CSS 在若干数值上并未按它实现，读文档时**以 CSS 为准**：

| 项目 | `DESIGN.md` 规范 | 当前实现 |
| --- | --- | --- |
| 正文字号 | 13px | 15px |
| 页签字号 | 14px | 15px |
| 主按钮 | 实心红 | 实心墨蓝（`--ink`） |
| 面板 / 按钮圆角 | 10px / 6px | 统一 `--radius: 4px` |
| 面板内边距 | 20–24px | 26px 28px |
| 卡片内边距 | 20–24px | `.stat-card` 20px 18px；`.course` 20px 24px 22px |

间距：区块 `margin-bottom` 26–34px；页签等宽相连、桌面最大 660px；触控区 ≥ 44px。

### 4.3 自定义属性动画

```css
@property --p {
  syntax: '<number>';
  initial-value: 0;
  inherits: false;
}
```

`--p` 只用于总进度环：`conic-gradient(var(--red) calc(var(--p) * 1%), ...)`，配合 `transition: --p .6s ease` 让环从 0 平滑转到目标百分比。`@property` 让浏览器知道它是数字，才能对自定义属性做过渡。

## 7. 响应式

| 断点 | 主要变化 |
| --- | --- |
| `<= 880px` | `.wrap` 内边距缩小；隐藏装订线；统计区改为三列、圆环独占一行；印章缩到 88px |
| `<= 560px` | 标题 28px、面板内边距 20/18；所有按钮最小高度 44px；输入框 16px 字号（防 iOS 聚焦缩放）；页签等分整行；今日卡底部按钮纵向铺满；待办头按钮换行；日历改为列表 |
| 新模块 `<= 560px` | 页签、今日卡、待办、日历、弹层各自的细节适配（3125–3380） |
| `prefers-reduced-motion` | 所有动画 / 过渡压缩到 0.001ms，只保留最终态 |

热力图的周数不是 CSS 断点，而是 `heatWeeks()` 按视口宽度算：`<560 → 13` 周、`<900 → 20` 周、否则 26 周；`resize` 防抖 200ms 后重建。

## 8. 可访问性

| 机制 | 实现 |
| --- | --- |
| 页签 | `role=tablist` / `role=tab` / `aria-selected` / `aria-controls`；当前项 `tabindex=0`，其余 `-1`；←/→/Home/End 切换 |
| 视图 | `role=tabpanel` + `aria-labelledby`；非当前视图 `hidden` |
| 弹层 | `role=dialog` + `aria-modal`；打开时焦点进入关闭按钮，关闭后回焦触发元素；Esc 关闭 |
| 进度环 | `role=img` + `aria-label`（含实际百分比） |
| 热力图 | 容器有说明性 `aria-label`；日期格按钮带日期与分钟数；未来日期 `aria-disabled="true"` 且移出 Tab 序列 |
| 日历 | 每个日期格 `aria-label` 包含当天待办数、最紧急档、视频时长与完成待办/打卡次数 |
| 状态 | 同步状态行 `role=status` + `aria-live=polite`；错误行 `role=alert` |
| 触控 | 560px 以下所有按钮 ≥ 44px 高 |
| 动效 | 尊重 `prefers-reduced-motion` |
| 兜底 | 2.5 秒未置 `data-app-ready=1` 时，直接在页面上提示强刷 |

## 9. 修改界面的检查清单

1. 新信息先问「它属于哪个视图」，不要在多个视图重复呈现（见第 3 节）。
2. 只用现有令牌取色，尤其不要给「类别」加颜色。
3. 新增可点元素：确保 560px 下 ≥ 44px，且有 `aria-*` 描述。
4. 新增动态 HTML：所有插值必须 `escapeHtml`，否则会破坏布局并带来 XSS 风险。
5. 新增折叠面板：复用 `.fold-panel` 三件套与 `applyFoldPanel` 的 `inert` 处理。
6. 改完样式：同步更新 `index.html` 里的 `?v=` 版本号。
